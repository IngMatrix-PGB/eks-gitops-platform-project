# Declarative, tracked source of truth for the project-local lab toolchain.
# Format: name|version|platform|filename|archive_type|archive_member|download_sha256|installed_sha256|url
#
#   archive_type    "raw" (the download IS the binary) or "tar.gz"
#                    (the download must be extracted first).
#   archive_member   For tar.gz only: the exact path of the binary inside
#                    the extracted archive. Empty for raw.
#   download_sha256  SHA256 of the file as downloaded (verified BEFORE
#                    any extraction is attempted).
#   installed_sha256 SHA256 of the file actually placed at .tools/bin/
#                    <filename> - identical to download_sha256 for raw
#                    tools; the extracted binary's own hash for archives.
#
# Read by scripts/lab/check-prerequisites.sh (read-only, verifies
# installed_sha256 against .tools/bin/<filename>) and
# scripts/lab/install-tools.sh (the only script allowed to write into
# .tools/). Never edited to point at "latest" or a floating URL.
#
# Exactly two supported platforms - darwin-arm64 (local development) and
# linux-amd64 (the GitHub Actions ubuntu-24.04 runner). Both scripts
# above detect the running OS/architecture via `uname` and process only
# the row(s) matching that platform; no other platform value is
# meaningful and no fallback across platforms is ever attempted. Every
# download_sha256/installed_sha256 below was verified against the
# corresponding official checksum published by the tool's own upstream
# release (kind's *.sha256sum file, dl.k8s.io's kubectl.sha256 file,
# get.helm.sh's *.tar.gz.sha256 file) before being recorded here.
